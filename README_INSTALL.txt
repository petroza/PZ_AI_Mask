PZ MASK v73 WIN11 LOCAL

Install package:
  PZ_MASK_v73_WIN11_LOCAL.zip

Recommended:
1. Extract the WHOLE ZIP.
2. Run INSTALL_PZ_MASK.bat.
3. Select the target folder.
4. Start the installed app with START.bat.
5. Open http://127.0.0.1:8080 (use 127.0.0.1, not localhost).

This is a local-only Windows app. Nothing is uploaded to any website.
First install needs internet and downloads several GB (PyTorch CUDA, models,
PHP); afterwards it runs offline.
