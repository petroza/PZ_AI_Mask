# Sources

This project is a local video masking app. The repository contains code and documentation only. Large AI weights and generated media are not bundled.

Main upstream projects:

- SAM2 Segment Anything 2: https://github.com/facebookresearch/sam2
- SAM2 checkpoints: https://dl.fbaipublicfiles.com/segment_anything_2/
- BRIA RMBG models: https://huggingface.co/briaai
- MatAnyone: https://github.com/pq-yang/MatAnyone
- FFmpeg: https://ffmpeg.org/
- PyTorch: https://pytorch.org/

Third party packages and models keep their own licenses.
